# 🌍 Global Radio

**Tune in to anywhere in the world.**

A free Android internet radio application for discovering and
listening to radio stations around the globe.

## Features

- Worldwide radio discovery
- Search stations by name
- Browse by country and genre
- Live streaming with Android Media3
- Background playback and media notification
- Favorites and listening history
- Custom streaming URLs
- No mandatory account
- Free to use

## Technology

- Kotlin
- Jetpack Compose
- Material 3
- Android Media3 ExoPlayer
- Radio Browser API
- Room database
- GitHub Actions

## Radio directory

Station discovery is powered by
[Radio Browser](https://www.radio-browser.info/).

The availability of stations and streams depends on their
broadcasters and internet connectivity.

## Build

The GitHub Actions workflow builds a debug APK automatically
when code is pushed to the main branch.
